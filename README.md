# Ballast

台股五檔加美股三檔 ETF 的**最小變異數投資組合**最佳化。前端 Streamlit，
最佳化用 cvxpy 解二次規劃。

## 資產池

| 市場 | 標的 | 來源 |
|---|---|---|
| 台股 | 2330 台積電、2412 中華電、1216 統一、2881 富邦金、2884 玉山金 | FinMind |
| 美股 ETF | SPY、TLT、GLD | yfinance |
| 匯率 | `TWD=X`（USD → TWD） | yfinance |

美股收盤價乘上**當日匯率**換算成台幣，兩邊用 inner join 只留下雙邊都有交易的日子，
再清掉零值（FinMind 在停牌日會回 `0.0`），存成 `prices.csv`。

## 報酬率一律用週資料

台北比紐約早收盤約十三個小時。用日資料會把台股的今天配上美股的昨天，
**跨市場相關性被嚴重低估**——最佳化因此誤判兩個區塊的分散效果。

實測（2019-01-02 ~ 2026-09-18，1811 個共同交易日 / 395 週）：

| 配對 | 日資料 | 週資料 |
|---|---|---|
| 台股 × 美股（平均） | **+0.010** | **+0.111** |
| 2330 × SPY | +0.099 | +0.372 |
| 台股內部（平均） | +0.455 | +0.403 |

日資料算出來台股和美股幾乎**零相關**，這在現實裡不成立。

關鍵在第三列：台股內部的相關性幾乎沒變（0.455 → 0.403），因為那些標的在同一個
時區、同時開收盤，沒有錯位問題。**只有跨市場的配對會暴增**——這正是時差造成的指紋，
而不是「換成週資料所有相關性都會上升」。

改用週資料（`W-FRI` 收盤）後兩邊落在同一個時間窗內，年化倍數因此是 **52**，不是 252。

App 裡的「為什麼用週報酬」展開區塊會用當下資料重算這張表。

## 模型

最小化投組變異數，四條限制式：

$$\min_w\ w^\top \Sigma w \quad \text{s.t.}\quad \sum w = 1,\ \ w \ge 0,\ \ w \le c,\ \ \mu^\top w \ge r_{\text{target}}$$

- `sum(w) == 1`　全額投入
- `w >= 0`　　　不可放空
- `w <= c`　　　單一標的上限
- `mu @ w >= target`　預期報酬下限

前端兩個滑桿控制 `c` 與 `target`，輸出權重長條圖與效率前緣曲線。

### c 的下限是 1/n

`c` 不能低於 `1/n`（本專案 n=8，即 12.5%）。低於這個值時上限和
「權重加總為 1」互相矛盾，**任何目標報酬都無解**。滑桿的 `min_value`
直接鎖在 `math.ceil(100/n * 10) / 10`，不讓使用者走進去。

目標報酬的可行區間也隨 `c` 變動：下限是全域最小變異數組合的報酬，
上限是把預算依報酬由高到低貪婪填到 `c` 為止所能拿到的報酬。

## 用法

```bash
pip install -r requirements.txt
python fetch_data.py          # 產生 prices.csv
streamlit run streamlit_app.py
```

FinMind 免費額度有限，量大時設定 token：

```bash
export FINMIND_TOKEN=your_token   # Windows: set FINMIND_TOKEN=...
```

抓不同期間：

```bash
python fetch_data.py --start 2015-01-01 --end 2026-09-19 --out prices.csv
```

## 已知偏誤：台股用未還原股價

這是本專案最大的一個已知偏誤，**刻意保留**，在這裡講清楚。

### 現況

台股價格來自 FinMind 免費的 `taiwan_stock_daily`，是**未還原權值**的收盤價。
除權息當天股價會直接扣掉配息金額，但現金實際上是進到股東口袋的——
在這份資料裡卻只看得到價格往下跳，看起來就像單純虧損。

美股那一側相反。`yfinance` 用 `auto_adjust=True` 抓的是**還原後**的價格，
SPY 和 TLT 的配息已經內含在報酬裡。

**兩邊的處理方式不一致，這才是真正的問題。** 如果兩邊都不還原，至少偏誤方向一致、
彼此還能比較；現在是台股被系統性地扣掉配息、美股沒有，差距全部算在台股頭上。

### 影響方向與量級

年化報酬被低估的幅度，大致等於各標的的現金殖利率：

| 標的 | 近年現金殖利率（約略） | 年化報酬被低估約 |
|---|---|---|
| 2330 台積電 | 1.5 ~ 2% | 1.5 ~ 2 個百分點 |
| 1216 統一 | 3% 上下 | 3 個百分點 |
| 2412 中華電 | 4% 上下 | 4 個百分點 |
| 2884 玉山金 | 4 ~ 5%（常含股票股利） | 4 個百分點以上 |
| 2881 富邦金 | 4 ~ 6%（逐年波動大） | 4 ~ 6 個百分點 |
| SPY / TLT / GLD | — | 0（已還原） |

殖利率數字是近年的約略區間，逐年變動不小，僅用來說明量級。
玉山金那種配股票股利的情況價格缺口更大，而且那完全不是損失。

連帶影響：

- **期望報酬 `mu`**：五檔台股全部被往下壓，**高殖利率的金融股和電信股被罰得最重**
  ——偏偏它們現實中的吸引力正是配息。
- **共變異數 `Sigma`**：除權息在週資料裡表現成一年一到兩次的獨立下跌，
  略微墊高個股變異數，也讓跨標的相關性被稍微低估。相較 `mu` 的偏誤，這個量級小得多。
- **最佳化結果**：偏誤主要透過 `mu' w >= target` 這條限制式傳導。
  台股 `mu` 被壓低，滑桿上的目標報酬一拉高，權重就會被推向美股 ETF。
  **目標報酬訂得越高，這個偏誤造成的扭曲越嚴重。**
  反過來說，滑桿拉在低檔、接近最小變異數組合時，影響相對有限，
  因為那一端主要由 `Sigma` 決定，而 `Sigma` 的偏誤小很多。

### 如果改用還原股價，結果會怎麼變

- 五檔台股的 `mu` 各自往上移約當殖利率，**2881、2884、2412 上移最多**，2330 最少。
- 除權息的價格缺口消失，台股的年化波動度會**略微下降**。
- 權重會從美股 ETF 移回台股，尤其是金融股和電信股。
- 整條效率前緣**往上、略往左移**；相同目標報酬下的波動度會比現在低。
- 2330 在五檔台股裡的相對優勢會被稍微稀釋，因為它的殖利率是五檔裡最低的。

### 三條修掉的路

1. **FinMind 付費 token 的 `taiwan_stock_daily_adj`**——最直接，換一個 dataset 名稱即可。
2. **用免費的 `taiwan_stock_dividend` 自己還原**——抓除權息紀錄，
   自行往回累乘調整因子。不用付費，但要自己處理股票股利與減資。
3. **改用 ETF 迴避**——把個股換成 0050、0056，`yfinance` 直接給還原後的價格。
   數字乾淨，但就失去「台股個股」的題目了，整個資產池會變成八檔 ETF。

目前選擇維持現狀並在這裡揭露：這個偏誤方向單一、可解釋，
而且不影響專案要示範的最佳化流程本身。

## 其他注意事項

- 期望報酬直接取歷史平均。均值-變異數最佳化對 `mu` 的估計誤差極度敏感，
  輸入差一點、權重可以差很多。
- 本專案僅供教學與實驗，不構成投資建議。
