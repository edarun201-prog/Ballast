# Ballast

台股五檔加美股三檔 ETF 的**最小變異數投資組合**最佳化。
前端 Streamlit，最佳化用 cvxpy 解二次規劃。

線上版：https://ballast-6dm4o4z7uqpcacpoxnwvxh.streamlit.app/

## 為什麼是這個，而不是現成工具

台灣市面上有數個資產配置工具，**沒有一個幫你算出配置**：

| | 台幣計價 | 支援台股個股 | 誰決定權重 | 算效率前緣 |
|---|---|---|---|---|
| Portfolio Visualizer（原版） | ✗ | ✗ | 可最佳化 | ✓ |
| YP 指投網 台英美股計算器 | ✓ | ✓ | **使用者自己填** | ✗ |
| 元大 投資組合計算器 | — | 僅台股 ETF | **使用者自己填** | ✗ |
| 阿爾發 投資組合分析 | — | — | 分析既有組合 | ✗ |
| **Ballast** | ✓ | ✓ | **求解** | ✓ |

（2026 年 9 月實地檢視。Portfolio Visualizer 原版只接受美股代號，
台灣使用者因此自建了數個克隆版。）

最能說明問題的是：功能最完整的 YP 指投網，計算器頁面底部連結到一篇叫
「想知道最佳的資產配置，效率前緣告訴你答案」的**文章**——他們知道使用者想要，
但工具裡沒有做。

### 跨市場帶來兩個現成工具沒處理的問題

一個同時持有台股與美股的台灣投資人，會遇到兩件事：

1. **匯率**——美股報酬必須換算成台幣才能跟台股相加。
2. **時差**——台北比紐約早收盤約十三個小時，這會讓日資料嚴重低估跨市場相關性
   （實測 +0.010 對 +0.111，見下節）。

第二點沒有任何一個現成工具處理，而它會實質改變最佳化的答案。

## 資產池

| 市場 | 標的 | 來源 |
|---|---|---|
| 台股 | 2330 台積電、2412 中華電、1216 統一、2881 富邦金、2884 玉山金 | FinMind |
| 美股 ETF | SPY、TLT、GLD | yfinance |
| 匯率 | `TWD=X`（USD → TWD） | yfinance |

美股收盤價乘上**當日匯率**換算成台幣，兩邊用 inner join 只留下雙邊都有交易的日子，
再清掉零值（FinMind 在停牌日會回 `0.0`），存成 `prices.csv`。
台股另外用 `TaiwanStockDividend` 做除權息還原（見下文），與美股那側的處理對齊。

另有 **0050 台灣50** 作為回測基準，存在 `benchmarks.csv`。
它只是尺，不是候選標的——0050 約一半是台積電，與 2330 相關係數 0.93，
當成持股等於買重複的東西；但當成「完全不動腦的報酬」正是該比的那條線。

## 報酬率一律用週資料

台北比紐約早收盤約十三個小時。用日資料會把台股的今天配上美股的昨天，
**跨市場相關性被嚴重低估**——最佳化因此誤判兩個區塊的分散效果。

實測（2019-01-02 ~ 2026-09-18，1811 個共同交易日 / 395 週）：

| 配對 | 日資料 | 週資料 |
|---|---|---|
| 台股 × 美股（平均） | **+0.010** | **+0.111** |
| 2330 × SPY | +0.099 | +0.372 |
| 台股內部（平均） | +0.455 | +0.403 |

日資料算出來台股和美股幾乎**零相關**，這在現實裡不成立。

關鍵在第三列：台股內部的相關性幾乎沒變（0.455 → 0.403），因為那些標的在同一個
時區、同時開收盤，沒有錯位問題。**只有跨市場的配對會暴增**——這正是時差造成的指紋，
而不是「換成週資料所有相關性都會上升」。

改用週資料（`W-FRI` 收盤）後兩邊落在同一個時間窗內，年化倍數因此是 **52**，不是 252。

App 裡的「為什麼用週報酬」展開區塊會用當下資料重算這張表。

## 除權息還原

台股價格來自 FinMind 免費的 `taiwan_stock_daily`，那是**未還原**的成交價：
除權息當天股價直接扣掉配息，在報酬率裡看起來就是一筆虧損，即使現金已經進了股東口袋。

美股那側相反——`yfinance` 的 `auto_adjust=True` 給的是還原價，SPY 和 TLT 的配息已內含。
**兩側處理不一致才是真正的問題**：偏誤單方向全算在台股頭上。

`fetch_data.py` 現在會另外抓 `TaiwanStockDividend`（免費，不需付費 token），
自行往回還原。除權息日當天，最後一個含權收盤價 P 對持有人的實際價值是

```
(P − 現金股利) / (1 + 股票股利 / 10)
```

現金離開股價；股票股利以每股面額 10 元計價，把一股拆成 1 + 股票股利/10 股。
該日之前的所有價格乘上這個比率，再往前逐次連乘。

### 實測影響

對照組用 `--no-adjust` 重跑一次，樣本 2019-01-02 ~ 2026-09-18：

| 標的 | 未還原年化 | 還原後年化 | 差 | 波動變化 |
|---|---|---|---|---|
| 2330 台積電 | 36.03% | 38.32% | +2.29pp | 26.32% → 26.24% |
| 2412 中華電 | 4.44% | 8.36% | +3.92pp | 9.51% → 8.37% |
| 1216 統一 | 2.56% | 6.37% | +3.81pp | 15.83% → 14.80% |
| 2881 富邦金 | 18.64% | 26.15% | **+7.51pp** | 23.83% → 22.70% |
| 2884 玉山金 | 12.89% | 20.13% | **+7.24pp** | 19.53% → 18.74% |
| SPY / TLT / GLD | — | — | **0.00pp** | 不變 |

美股三檔一動也沒動，這是調整只作用在該作用之處的證據。

高殖利率的金融股被低估最多——超過 7 個百分點。玉山金那種同時配股票股利的，
價格缺口更大，而那完全不是損失。波動度也一併下降，因為除權息的假跌幅消失了。

### 對最佳化結果的影響

同樣的設定（c = 30%、目標報酬 12%）：

| | 未還原 | 還原後 |
|---|---|---|
| 年化波動 | 7.97% | **7.46%** |
| 2881 富邦金 | ~0% | 3% |
| 2884 玉山金 | ~0% | 3% |
| SPY 美股大盤 | 11% | 8% |
| 1216 統一 | 7% | 13% |

金融股從幾乎被排除變成進入投組，權重整體從美股移回台股，相同報酬下的波動降低約
半個百分點。**偏誤不只是數字難看，它會改變配置決策**——這也是為什麼不能用
「反正兩邊都有誤差」帶過。

`--no-adjust` 保留在 CLI 裡，上面那張對照表隨時可以重跑驗證。

## 模型

最小化投組變異數，四條限制式：

$$\min_w\ w^\top \Sigma w \quad \text{s.t.}\quad \sum w = 1,\ \ w \ge 0,\ \ w \le c,\ \ \mu^\top w \ge r_{\text{target}}$$

- `sum(w) == 1`　全額投入
- `w >= 0`　　　不可放空
- `w <= c`　　　單一標的上限
- `mu @ w >= target`　預期報酬下限

前端兩個滑桿控制 `c` 與 `target`，輸出權重長條圖與效率前緣曲線。

### c 的下限是 1/n

`c` 不能低於 `1/n`（本專案 n=8，即 12.5%）。低於這個值時上限和
「權重加總為 1」互相矛盾，**任何目標報酬都無解**。滑桿的 `min_value`
直接鎖在 `math.ceil(100/n * 10) / 10`，不讓使用者走進去。

目標報酬的可行區間也隨 `c` 變動：下限是全域最小變異數組合的報酬，
上限是把預算依報酬由高到低貪婪填到 `c` 為止所能拿到的報酬。

## 回測不能用最佳化那段歷史

最佳化是用**全部**歷史配適的，用同一段歷史給它打分等於自己考自己。
`backtest.py` 問的是另一個問題：如果當年只看得到當下為止的資料、
每隔一段時間重新求解一次，實際會拿到什麼。

每次求解只看前 156 週（約三年），持有接下來 4 週，**持有期完全在求解視窗之外**。

樣本外 2022-01-28 ~ 2026-09-18，239 週、60 次再平衡：

| | 累積報酬 | 年化 | 年化波動 | Sharpe | 最大回撤 | 每次換手 |
|---|---|---|---|---|---|---|
| Ballast（純最小變異） | 58.97% | 10.61% | **7.51%** | 1.21 | **-12.58%** | 2.30% |
| 等權重 1/N | 107.86% | 17.26% | 9.50% | **1.66** | -15.98% | — |
| **0050 台灣50** | **242.77%** | **30.74%** | 20.72% | 1.41 | -31.36% | — |
| SPY 美股大盤 | 113.12% | 17.90% | 14.92% | 1.10 | -15.87% | — |
| 2330 台積電 | 316.41% | 36.39% | 27.45% | 1.27 | -40.67% | — |

**它輸給無腦買 0050，也輸給等權重。** 這張表放在 app 最顯眼的位置，不是藏起來的。

該看的是它在最佳化的東西：**波動與回撤都是全場最低**，回撤只有 0050 的四成。
0050 中途最深跌 31%，這個組合跌 12.6%。這是兩種不同的產品，
不是同一個產品的好壞版本——問題不在哪個報酬高，而在持有人能不能在帳面跌三成時不賣掉。

等權重的 Sharpe 最高也不是實作出錯，是
[DeMiguel, Garlappi & Uppal (2009)](https://doi.org/10.1093/rfs/hhm075)
的結論在這組資料上重現：用歷史平均估期望報酬的誤差太大，
1/N 這種完全不估計的做法反而難以擊敗。

**換手率要一起看。** 目標報酬拉越高，最佳化越要追前一個視窗裡剛好表現好的標的：
無目標時每次換手 2.30%，目標 18% 時變成 11.20%。而上表**未扣任何交易成本**，
台股賣出還有 0.3% 證交稅。

## 用法

```bash
pip install -r requirements.txt
python fetch_data.py          # 產生 prices.csv
streamlit run streamlit_app.py
```

FinMind 免費額度有限，量大時設定 token：

```bash
export FINMIND_TOKEN=your_token   # Windows: set FINMIND_TOKEN=...
```

```bash
python fetch_data.py --start 2015-01-01 --end 2026-09-19 --out prices.csv
```

## 部署

這是個展品，但要能真的用，所以資料有兩層：

1. **`prices.csv` 有 commit 進 repo**——clone 下來、或雲端第一次開，立刻就有畫面，
   不需要 token、不需要等抓取。數字是 commit 當下的快照，展示時穩定不會變。
2. **App 裡有「更新資料」按鈕**——想看最新數字就按，現抓 FinMind 和 yfinance。

### 放上 Streamlit Community Cloud

1. [share.streamlit.io](https://share.streamlit.io) 用 GitHub 帳號登入
2. New app，選這個 repo、branch `main`、main file `streamlit_app.py`
3. Advanced settings → Secrets 填（沒有 token 也能跑，免費額度較緊）：

   ```toml
   FINMIND_TOKEN = "你的 token"
   ```

### 雲端上「更新資料」的行為

Streamlit Cloud 的檔案系統是**暫時的**。按更新會把新的 `prices.csv` 寫進容器，
那個 session 和後續訪客都看得到新數字——但容器一重啟（閒置休眠、重新部署）就會消失，
退回 repo 裡 commit 的那份快照。

對展品來說這反而是好事：**它會自己回到一個已知可用的狀態**，不會因為某次抓取抓到
爛資料就一直爛下去。想讓快照跟上，重跑 `python fetch_data.py` 然後 commit。

更新失敗（網路斷、FinMind 額度用盡）時，app 顯示警告並沿用現有資料。
新資料是先寫暫存檔、完整了才換上去的，所以一次失敗的抓取不可能讓畫面壞掉。

## 限制與已知問題

### 為什麼只有八檔標的

不是偷懶，是資料長度的硬限制。共變異數矩陣要估 `n(n+1)/2` 個參數，
而我們只有 395 週觀測：

| n | 參數量 | 每參數分到的觀測數 |
|---|---|---|
| 8 | 36 | 88 |
| 100 | 5,050 | 7.8 |
| 400 | 80,200 | 2.0 |

當 **n ≥ 395**，樣本共變異數矩陣秩不足而**奇異**——此時存在估計變異數恰好為零的投組，
那是純粹的雜訊，而最小變異數最佳化會選中它。那不是「估得不準」，是無定義。
台股上市逾千家，遠在這道牆的另一側。

更根本的是，**最佳化器用不到那麼多標的**。以已知真實共變異數做模擬，
給最小變異數最佳化 n 檔候選，它實際的有效持股數（`1 / Σw²`）是：

| 給它幾檔 | 有效持股數 |
|---|---|
| 20 | 5.5 |
| 50 | 7.2 |
| 100 | 10.1 |
| 300 | 14.9 |

不可放空加上單一上限，使解天生稀疏。給它一千檔不會得到一千檔的投組，
只會得到同樣十幾檔，而且是被估計雜訊挑出來的那十幾檔。

要擴大標的數，該做的是兩段式架構——先用大 universe **篩選**，
再對挑出的 10~30 檔**配置**；或改用收縮估計（Ledoit-Wolf）與因子模型。
那是換引擎，不是加資料。

### 標的選擇本身帶有後見之明

Walk-forward 解決了權重選擇偷看未來，**沒有解決標的選擇偷看未來**。
這八檔是今天挑的，而今天我們已經知道誰漲了。

實測過把 NVDA、AAPL 等美股科技股加進資產池：在高目標報酬下波動可降 1.72 個百分點。
但 NVDA 過去七年年化 65% 是現在才知道的事，2019 年沒有人會把它當成穩健分散工具。
那個改善本質上是「我們挑了漲最多的那支」，因此**沒有採用**。

### 期望報酬用歷史平均

均值-變異數最佳化對 `μ` 的估計誤差極度敏感，且是往壞的方向放大——
它會把最大權重給估計值被高估最多的標的（Michaud 的 error maximization）。
這是上面回測中 1/N 難以擊敗的根本原因。

### 回測的其他保留

- 樣本外僅四年多（2022-01-28 起），且該期間為多頭；低波動策略在多頭中本就落後。
- 所有績效數字**未扣交易成本**。台股賣出有 0.3% 證交稅，換手率高的設定受影響最大。
- 再平衡假設以收盤價成交，未計滑價與流動性。
